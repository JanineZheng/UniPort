# Uniport 品牌 UI 升级

2026-10-22。本次在已有 UnitPort MVP 上接入用户提供的新版 Logo 与精确色板，延续现有产品交互。

## 配色与应用

| 品牌色 | 色值 | 用途 |
| --- | --- | --- |
| Port Lime | #D9FF6B | 活跃工具、换算结果卡、收藏状态、规格结果表头、重点操作文字 |
| Ink | #0F0F0F | 顶部品牌栏、工具导航、主文字、复制按钮 |
| Cloud | #F7F7F5 | 页面与输入面板背景、深色背景上的 Logo |
| Slate | #717571 | 次要元素，正文辅助说明使用更深的语义色保证可读性 |

品牌基础色和语义变量集中在 `src/styles.css`。白色用于工作区表面，红色与琥珀色保留为错误/时间歧义的语义提示色。青柠色不用于白底小字，优先与墨黑搭配。

## 资源

- 顶部：`public/brand/uniport-horizontal-transparent-white.svg`。
- 介绍区域与导航辅助图形：`public/brand/uniport-logo-transparent-white.svg`。
- 同时保留浅色背景对应的透明 SVG，便于后续复用。
- 浏览器标签使用 `favicon.svg` 与多尺寸 `favicon.ico`；iOS 使用 `apple-touch-icon.png`。
- `public/brand/palette.json` 保留用户品牌色板。
- 工具、语言、交换及复制按钮使用统一线条 SVG 图标；纯装饰图标不进入无障碍名称。

本地原始素材目录为工作区的 `output/uniport/vector/`，原始素材未修改。网站源码放在当前工作区 `outputs/UniPort/`，从上一版 MVP 保留 Git 历史与依赖锁文件后继续开发。

## 界面

- 桌面：品牌栏、简洁介绍、市场设置、深色工具侧栏与浅色工具工作区。
- 手机：紧凑品牌栏、双列市场选择、两行工具入口、纵向输入/结果卡。
- 长度、重量、容量、温度、时区、商品规格和汇率预留面板共享同一套表单、卡片、按钮与状态样式。
- 保留键盘焦点、禁用状态、错误提示、复制反馈及减少动态效果偏好。

## 本次验证

- 26 项既有核心测试全部通过；TypeScript 检查和 Vite 生产构建通过。
- 在浏览器检查 1440 × 1080 桌面与 390 × 844 手机布局。
- 检查中英文切换、Logo 与图标加载、页面宽度及控制台；未发现缺失图片、横向溢出或控制台错误。

- 手机端实际复制 `2.54 cm → 1 in` 和批量规格 `SKU-001 — Dimensions (L × W × H): 10 × 20 × 30 in; Weight: 1 lb.`。
- 后续完整浏览器自动化回归已补跑，整合布局与 SEO 后 46 项桌面/手机用例及 22 项测试域名 SEO 专项通过；详情见 [验证记录](VALIDATION.md)。
- 未增加依赖，未改动换算引擎、国家配置和本地存储 schema；本次交付仅功能分支与 PR，不合并、不部署。
