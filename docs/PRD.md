# UnitPort MVP · 产品设计与实施计划

版本：0.1 · 2026-10-22。产品名 UnitPort，GitHub 仓库名保留 UniPort。

## 产品目标

为全球跨境卖家提供无登录的浏览器换算工作台。默认中国 → 美国，减少商品上架、国际协作中的单位与时间错误。首版不依赖后端，不上传商品数据。

核心用户任务：选择目标市场 → 确认/修改推荐单位 → 输入数值或粘贴规格 → 复制可用结果。

## 范围与验收

| 功能 | MVP 行为与验收标准 |
| --- | --- |
| 国家 / 市场 | 首次 CN → US；支持 12 个初始市场；切换某一侧仅重置该侧推荐单位和城市，不锁定任何单位 |
| 本地偏好 | 保存语言、两国、单位、城市、小数位、收藏；刷新恢复；存储禁用/损坏时可继续使用 |
| 常用市场 | 默认美国、英国、日本；可增删收藏；点击收藏切换目标市场 |
| 通用换算 | 长度、重量、容量、温度；同类单位自由组合；零值有效、非法输入明确报错；温度下限为绝对零度 |
| 计量定义 | oz 仅为常衡重量；US fl oz / Imperial fl oz 明确区分；不提供质量与容量互算 |
| 精度 | 有限小数输入转 BigInt 分数，过程不舍入；仅显示/复制时按 2/4/6 位四舍五入（负数中点远离零）；极小非零数保留有效数字 |
| 商品规格 | 每行可选 SKU + 长宽高 + 重量；支持 TSV 或简单 CSV；最多 500 行；逐行报错；全部有效才能复制英文 |
| 时区 | 国家配置给出城市和 IANA ID；输入具体日期时间；DST 不存在时间阻止输出；重复时间必须明确选择第一次/第二次 |
| 双语 / 响应式 | 所有主要界面与错误提示支持中英；键盘可操作；桌面侧栏与移动网格导航；无横向溢出 |
| 汇率 | 仅显示两国货币代码及未接入提示；预留 Provider contract，不展示虚构报价 |

首批市场：CN、US、GB、JP、DE、FR、CA、AU、BR、KR、AE、IN。此列表是可扩展配置，不代表全球国家/城市已全覆盖。

视觉方向：柔和米白背景、深绿色品牌、浅绿结果卡。工具工作区优先于营销内容，不引入素材下载或外部字体。

## 技术边界

- `config/markets.ts`：国家名称、货币代码、推荐单位 ID、IANA 城市；不含计算系数。
- `core/units.ts` + `core/convert.ts`：单位定义和纯计算；不导入国家配置。
- `core/timezone.ts`：基于浏览器 Intl / IANA 数据，独立于国家。
- `core/specs.ts`：组合通用引擎，输出固定英文规格。
- `core/preferences.ts`：存储 schema v1、字段校验、容错。
- `App.tsx`：编排状态与交互；组件不参与数学规则。
- `core/currency.ts`：未来报价应包含来源、更新时间；当前无数据源。

## 下一阶段
